# 💬 하루 채팅 카운터 봇

텔레그램 채팅방의 **오늘 채팅 개수**를 세는 봇입니다. 매일 **자정(한국 시간)** 에 0으로 초기화되고,
지난 기록은 날짜별로 쌓여서 **미니앱에서 기간별 통계**로 볼 수 있어요.

## 사용법
| 명령어 | 설명 |
|---|---|
| `/채팅` | 내 오늘 채팅 개수 + 순위 보기 (`/chat`, `/count` 도 가능) |
| `/랭킹` | 오늘 채팅 순위 (페이지당 10명, ◀️ ▶️ 버튼으로 넘김 · `/rank` 도 가능) |
| `/통계` | 기간별 통계 미니앱 열기 (`/stats` 도 가능) |
| `/start` | 봇 소개 |

## 설치 & 실행
```bash
pip install -r requirements.txt
export BOT_TOKEN="123456:ABC..."   # @BotFather 에서 받은 토큰
python bot.py
```

선택 환경변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `BOT_TIMEZONE` | `Asia/Seoul` | 자정·날짜 기준 시간대 |
| `DB_FILE` | `haru.db` | 통계 저장 파일 (SQLite) |
| `WEB_HOST` | `127.0.0.1` | 미니앱 서버 주소 |
| `WEB_PORT` | `8765` | 미니앱 서버 포트 (`0` 이면 끔) |
| `APP_SHORT_NAME` | (없음) | BotFather `/newapp` 으로 만든 경우 그 short name |

> 예전 버전의 `counts.json` 이 있으면 처음 실행할 때 오늘 기록을 DB로 자동으로 옮기고 `counts.json.migrated` 로 이름을 바꿔요.

## ⚠️ 꼭 해야 할 설정
그룹의 모든 메시지를 세려면 봇이 메시지를 볼 수 있어야 합니다. 둘 중 하나:
1. @BotFather → `/setprivacy` → 봇 선택 → **Disable** (그 후 봇을 그룹에서 내보냈다가 다시 초대)
2. 또는 봇을 그룹 **관리자**로 지정

## 📊 통계 미니앱

그룹에서 `/통계` → **📊 통계 열기** 버튼을 누르면 열려요. (`/채팅`, `/랭킹` 결과 밑에도 버튼이 있어요)

- 기간: 오늘 · 어제 · 7일 · 30일 · 전체 · 📅 달력(시작일 → 종료일 터치)
- 요약: 메시지 수(이전 기간 대비 ▲▼%), 참여 인원, 하루 평균, 최고의 날 / 피크 시간
- 일별 그래프(메시지 + 참여 인원), 시간대별 그래프, 요일×시간 히트맵
- 기간별 순위 (10명씩 페이지 넘김, 내 순위 바로가기)
- 이름을 누르면 개인 통계 (순위, 점유율, 활동일, 일별·시간대 그래프, 메시지 종류)
- 메시지 종류(텍스트·사진·영상·스티커·GIF·음성·파일), 멤버 입장/퇴장/강퇴 수
- **그 방의 멤버만** 볼 수 있어요 (텔레그램 서명 확인 + 멤버 확인)

### 설정 방법
미니앱은 **HTTPS 주소**가 꼭 필요해요. 봇이 `127.0.0.1:8765` 에 띄운 서버를 HTTPS로 연결해주세요.

**A. 도메인이 있으면 (추천) — Caddy가 인증서까지 자동으로**
```bash
sudo apt install -y caddy
echo 'stats.내도메인.com {
    reverse_proxy 127.0.0.1:8765
}' | sudo tee /etc/caddy/Caddyfile
sudo systemctl reload caddy
```
도메인 DNS에 A 레코드(`stats` → 서버 IP)를 추가하고, 서버 방화벽에서 80·443 포트를 열어주세요.

**B. 도메인이 없으면 — Cloudflare 임시 터널 (테스트용)**
```bash
cloudflared tunnel --url http://localhost:8765
```
출력되는 `https://xxxx.trycloudflare.com` 주소를 쓰면 돼요. 단, 터널을 다시 켤 때마다 주소가 바뀌어서 BotFather에서도 다시 바꿔줘야 해요.

**BotFather 설정**
1. @BotFather → `/mybots` → 봇 선택 → **Bot Settings** → **Configure Mini App** → **Enable Mini App**
2. 위에서 만든 HTTPS 주소 입력 (예: `https://stats.내도메인.com`)

> `/newapp` 으로 미니앱을 따로 만들었다면 그 short name 을 `APP_SHORT_NAME` 환경변수로 넣어주세요.

## 🚫 들낙 방지 (자동 영구 차단)
방을 **스스로 나간 사람**은 조용히 영구 차단되고, "OOO님이 나갔습니다" 자동 메시지도 지워져요. 관리자가 내보낸 경우는 건드리지 않아요.

- 봇이 그룹 **관리자**이고 **사용자 차단(Ban users)**, **메시지 삭제(Delete messages)** 권한이 있어야 해요.
- 차단을 풀려면: 그룹 설정 → 차단된 사용자(Removed users) → 해당 사람 해제
